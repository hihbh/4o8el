# MR.ADAM — تشغيل السيرفر

كل البيانات (الطلاب، الحضور، الواجبات، الامتحانات، الرسائل...) بتتحفظ في قاعدة بيانات SQLite على السيرفر،
والفيديوهات بتتخزن كملفات على ديسك السيرفر. أي جهاز يفتح الرابط يلاقي نفس البيانات. مفيش Firebase ولا أي خدمة خارجية.

## التشغيل
المطلوب: Node.js 22.5 أو أحدث (بدون npm install).

    TEACHER_USER=اسم_سري_للمدرس ASSISTANT_USER=اسم_سري_للمساعد node server.js

ثم افتح http://localhost:3000

متغيرات اختيارية: PORT (3000) و DATA_DIR (مجلد data جنب الملف).

## مهم قبل النشر
- غيّر TEACHER_USER و ASSISTANT_USER. لو سبتهم الافتراضي (1 و 2) أي حد يعرف الرابط يدخل مدرس.
- أول تشغيل بيبدأ بالبيانات التجريبية؛ من الإعدادات تقدر تمسحها (إعادة ضبط البيانات) وتبدأ من الأول.
- الكاميرا (مسح QR) على الموبايل لازم الموقع يشتغل HTTPS.
- خد نسخة احتياطية دورية من مجلد data (فيه app.db والفيديوهات).

## الاستضافة
تحتاج مكان يشغّل Node ويحتفظ بالديسك (persistent disk): VPS عادي، أو Railway / Fly.io مع Volume،
أو جهاز في البيت مع Cloudflare Tunnel. استضافات الديسك المؤقت (زي الخطة المجانية في Render) هتفقد البيانات.
